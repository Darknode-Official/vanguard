# VANGUARD

Autonomous Attack Surface Intelligence Engine — 10-phase automated penetration testing reconnaissance.

Part of the [Darknode](https://darknode.ai) cybersecurity platform.

## Features

- **Phase 1:** DNS Reconnaissance (all record types via Google DoH)
- **Phase 2:** Subdomain Discovery (crt.sh + brute force)
- **Phase 3:** Host Probing (HTTP/HTTPS with timing)
- **Phase 4:** Technology Fingerprinting (28 signatures)
- **Phase 5:** Security Header Assessment (A-F grading)
- **Phase 6:** CVE Correlation (NVD API + CISA KEV)
- **Phase 7:** Infrastructure Analysis (geolocation, ASN reputation)
- **Phase 8:** Email Security Audit (SPF, DMARC, DKIM)
- **Phase 9:** Attack Surface Scoring (0-100 risk, MITRE ATT&CK)
- **Phase 10:** Report Generation (HTML + JSON export)
